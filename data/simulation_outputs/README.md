# Simulation outputs

This folder contains the nine synthetic datasets generated by the final NetLogo agent-based model and used in the Orange Data Mining analyses.

Three independent runs were generated for each population size:

- 1,000 agents: `1000-1.csv`, `1000-2.csv`, `1000-3.csv`
- 5,000 agents: `5000-1.csv`, `5000-2.csv`, `5000-3.csv`
- 10,000 agents: `10000-1.csv`, `10000-2.csv`, `10000-3.csv`

These files contain synthetic data only and do not represent real individual patients.

The datasets were used for K-means clustering, decision-tree analysis, and stability assessment across population sizes.
