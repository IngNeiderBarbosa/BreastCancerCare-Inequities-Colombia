# Orange Data Mining workflow

This folder contains the Orange Data Mining workflow used for exploratory clustering, decision-tree analysis, and performance evaluation in the study:

**Agent-Based Simulation and Data Mining for Mapping Structural Inequities in Breast Cancer Care Pathways in Colombia: A Computational Proof-of-Concept Study**

## Purpose

The Orange workflow was used to analyse synthetic data generated by the NetLogo agent-based simulation model.

Its objective was not to develop a clinical prediction tool, but to explore recurrent hierarchical patterns associated with synthetic cumulative care-burden profiles.

## Analytical workflow

The main steps implemented in Orange were:

1. Import synthetic outputs generated by NetLogo.
2. Select predictor variables.
3. Exclude variables that could introduce information leakage.
4. Apply K-means clustering to residual energy.
5. Generate three ordered cumulative care-burden profiles.
6. Train interpretable decision-tree models.
7. Evaluate classification performance using stratified 10-fold cross-validation.
8. Compare recurrent variables and model stability across simulation sizes.

## Predictor variables

The final decision-tree analysis included:

- age;
- insurance scheme;
- history-related variables;
- offspring;
- breastfeeding status;
- left-breast mass;
- right-breast mass.

Variables directly involved in constructing the target were excluded from the predictor set to reduce information leakage.

These excluded variables included:

- diagnostic duration;
- treatment duration;
- accumulated care time;
- cumulative burden components;
- continuous residual energy.

## Decision-tree configuration

The final decision-tree configuration used:

- maximum tree depth: 3;
- minimum number of instances in leaves: 30;
- no splitting of subsets containing fewer than 40 instances;
- stopping when the majority class reached 95%.

## Model evaluation

Performance was assessed using stratified 10-fold cross-validation.

Reported metrics included:

- Area Under the ROC Curve (AUC);
- Classification Accuracy (CA);
- F1 score;
- Precision;
- Recall;
- Matthews Correlation Coefficient (MCC).

## Simulation scenarios

The Orange workflow was applied to synthetic populations of:

- 1,000 agents;
- 5,000 agents;
- 10,000 agents.

Three independent simulation runs were analysed for each population size.

## Interpretation

Decision-tree outputs are interpreted as exploratory representations of recurrent hierarchical patterns within the synthetic populations.

They should not be interpreted as:

- patient-level clinical predictions;
- diagnostic models;
- prognostic models;
- causal estimates;
- tools for individual patient prioritisation.
