# BreastCancerCare-Inequities-Colombia

Reproducible materials for the study:

**Agent-Based Simulation and Data Mining for Mapping Structural Inequities in Breast Cancer Care Pathways in Colombia: A Computational Proof-of-Concept Study**

## Overview

This repository contains the computational materials used to support a proof-of-concept framework integrating publicly available Colombian health data, agent-based simulation, and interpretable data-mining techniques to explore structural inequities in breast cancer care pathways.

The repository is intended to support transparency and reproducibility. The computational framework is exploratory and should not be interpreted as a clinical prediction or patient-level decision-support system.
